# 주간 해외 동향 리포트

USMEF Korea 뉴스라인 1페이지의 PDF를 모두 읽어 미국 소고기 시장 데이터를 Excel 파일로 저장하는 Python 프로그램입니다.

생성되는 Excel의 열은 아래와 같습니다.

- `구분`: 뉴스라인의 발행일(최신순)
- `도축두수`: 미국 소고기 주간 도축두수(천두 단위)
- `미국($/lb)`: Choice 등급 소고기 컷아웃 가격(달러/파운드)

## 준비물

- Python 3.10 이상
- 인터넷 연결

## 설치 및 실행

PowerShell 또는 터미널에서 프로젝트 폴더로 이동한 뒤 아래 명령을 순서대로 실행하세요.

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python main.py
```

실행이 끝나면 다음 파일이 생성됩니다.

```text
output/usmef_weekly_market_report.xlsx
```

뉴스라인 PDF는 먼저 내장 텍스트에서 필요한 숫자를 읽습니다. 텍스트가 없는 일부 이미지형 호만 한국어 OCR로 자동 전환하므로, 일반적인 주간 현행화는 훨씬 빠르게 처리됩니다. 처음 OCR이 필요한 실행에서는 모델 준비에 시간이 조금 더 걸릴 수 있습니다.

## 웹페이지로 실행하기

Windows에서 이미 설치를 완료했다면 프로젝트 폴더의 **`서버실행.bat`를 더블클릭**하세요. 프로젝트의 `.venv`로 5002번 서버를 실행하고 준비가 끝나면 기본 브라우저에서 `http://127.0.0.1:5002/`를 엽니다. `.env`는 기존처럼 앱에서 읽으며, 실행파일에 API 키를 넣지 않습니다. 실행 중에는 검은 서버 창을 열어 두고, 종료하려면 그 창에서 `Ctrl+C`를 누르세요. 배치파일만 다른 곳으로 옮기지 말고 바로가기를 만드세요.

이미 이 프로젝트 서버가 실행 중이면 **`Y` 입력 없이 유휴 상태를 확인한 뒤 자동 재시작**해 현재 저장된 새 코드를 불러옵니다. 실행파일 경로·`app.py` 명령·프로세스 생성시각·5002번 포트 소유를 대조한 이 프로젝트 서버만 종료하며, 다른 프로그램이나 다른 프로젝트 서버는 건드리지 않습니다. **기사·보고서 작업이 진행 중이거나 작업 상태 조회에 실패하면 기존 서버를 유지**하고 중단합니다. 작업 상태 조회 기능이 없는 구버전 서버도 자동 종료하지 않습니다. 필요한 경우 모든 작업을 마친 뒤 기존 서버 창에서 `Ctrl+C`로 직접 종료하세요. 서버가 없으면 곧바로 시작하며 준비 후 브라우저를 엽니다. 콘솔에는 새 서버의 문체 버전과 PID도 표시합니다. 다른 프로그램이 5002번 포트를 사용하거나 Python 환경·소유정보를 확인하지 못하면 안내를 표시하고 실행하지 않습니다. 자동 시작 등록·관리자 권한 요청·보안 설정 변경·다른 Python 프로세스 일괄 종료는 하지 않습니다. 확인 입력을 사용하는 수동 방식은 `python scripts/start_web.py --restart`로 실행할 수 있습니다.

아래처럼 직접 실행하는 방식도 사용할 수 있습니다. `PORT`를 지정하지 않은 앱 자체 기본 포트는 5000이며, 위 배치파일은 5002를 명시합니다.

```powershell
.\.venv\Scripts\Activate.ps1
python app.py
```

브라우저에서 `http://127.0.0.1:5000`을 열고 **보고서 생성** 버튼을 누르세요. 업로드한 양식의 비어 있는 주차 행을 찾아 다음 항목을 현행화합니다.

- `소-미국`, `돼지-미국`: 다음 주 수요일 USMEF 뉴스라인의 도축두수와 컷아웃 가격
- `소-호주`: MLA의 주간 소 도축 합계, Eastern States Young Cattle Indicator(EYCI), AUD/KRW 환율
- `돼지-EU(독일)`: AHDB 원본 Excel의 `Week ended` 날짜와 일치하는 독일 Grade E 가격(유로/100kg)
- `계란-일본`: 주차 행의 날짜와 일치하는 JA 전농타마고 도쿄 M란 기준치(엔/kg)
- `계란-미국`: USDA Market News의 6-Area 주간 재고량과 National Shell Eggs - Caged Large 평균가격
- `닭-미국`: USDA Market News Slug ID `3208`의 Chicken (Young) 주간도축량과 Slug ID `3646`의 National Composite WOGS `Wtd Avg` 가격(cents/lb)
- `닭-브라질`: CEPEA 동결 닭고기 가격 시리즈의 동일 날짜 `À vista R$` 가격과 BRL/KRW 환율

### 해외 축산 동향 기사 초안 12종

웹페이지의 **기사 초안** 탭에서 소·돼지·닭·계란별 현지동향 2개와 국내기사 1개, 총 12개 항목을 처리합니다.

| 축종 | 첫 번째 현지동향 | 두 번째 현지동향 | 국내기사 |
|---|---|---|---|
| 소 | 미국 · USMEF 뉴스라인 소고기 시장동향 | 호주 · MLA Latest News | 해외 소고기 관련 한국어 보도 |
| 돼지 | 미국 · 같은 USMEF의 돼지고기 시장동향 | EU(독일) · EuroMeatNews | 해외 돼지고기 관련 한국어 보도 |
| 닭 | 미국 · Brownfield Ag News | 브라질 · AviSite | 해외 닭고기 관련 한국어 보도 |
| 계란 | 미국 · Brownfield Ag News | 일본 · JA 전농·전농타마고 뉴스 및 공개 리포트 | 해외 계란 관련 한국어 보도 |

기사 초안의 보고 기준일 기본값은 **오늘 날짜**입니다. 날짜를 직접 선택하면 선택값은 다른 작업 탭을 오가도 유지됩니다.

기사 기간은 **보고 기준일이 속한 주의 일요일~토요일(양 끝 날짜 포함)**입니다. 예를 들어 2026-10-01(목)을 선택하면 2026-09-27~10-03에 발행된 기사만 확인합니다. 12개 항목의 지정 매체·NAVER·Google 등 보완 검색에 동일하게 적용하며 보고일 이후라도 같은 주의 금·토요일을 제외하지 않습니다. 아직 오지 않은 날짜의 기사는 공개된 후 다시 실행하면 확인할 수 있습니다. 현지동향 8개는 지정 매체 원문을 확보했더라도 공개 뉴스 검색 후보와 비교합니다. 국내기사는 기존 NAVER 우선·공개 검색 보완 방식을 유지합니다. 검색 결과나 헤드라인만으로 초안을 쓰지 않고, 실제 원문의 발행일·본문·언어·국가·축종을 확인합니다. 로그인, Cookie, 접속 제한 우회는 사용하지 않습니다.

일본 계란은 JA 전농타마고의 공개 날짜별 시세 조회도 확인하며, 조회일과 원문의 실제 발표일이 일치하는 자료만 사용합니다. 미국 계란의 USDA 보고서는 `about steady to lower` 같은 가격 수식어와 `moderate to fully adequate` 같은 공급 범위를 각각 보존해 한국어 개조식으로 정리합니다. Brownfield·USDA에서 원문을 확보하지 못하면 IndexBox의 공개 계란 뉴스 목록에서 해당 주차의 미국 시장 보도를 추가 확인합니다. 이때 광고·상품 카드를 제외한 기사 본문과 실제 발행일을 확인하고 매체명을 IndexBox로 표시하며, 수요지수의 전주 대비 **포인트 변화**를 가격·퍼센트 변화로 바꾸지 않습니다. 해석 가능한 정형 원문은 모델 재시도 없이 요약하되, 날짜·원문 근거·40자 이상·문장 완결성 검사는 그대로 적용합니다.

국내기사는 **NAVER 뉴스 API를 우선** 사용합니다. 재발급한 인증정보를 프로젝트 루트의 비공개 `.env`에 아래 변수명으로 넣고 서버를 다시 시작하세요. 값은 채팅·소스·GitHub에 올리지 않습니다. NAVER가 연결되지 않거나 적합한 후보가 없으면 공개 Google 뉴스로 보완하지만 검색 결과를 확보하지 못할 수 있습니다.

```dotenv
NAVER_CLIENT_ID=발급받은_Client_ID
NAVER_CLIENT_SECRET=발급받은_Client_Secret
```

수집·요약 처리량 기반 진행률과 전체 경과시간을 표시하며, 완료된 초안부터 카드에 나타납니다. **보고서 문구 복사**는 완료된 항목만 소→돼지→닭→계란 순서로 복사합니다. 현지동향은 `-(현지동향) 요약`, 국내기사는 `∙ “제목”(매체,월.일.)`와 다음 줄 `- 요약` 형식입니다.

#### 과거 주차 원문과 요약 실패 처리

- 최신 목록뿐 아니라 매체가 공개한 날짜별 검색·아카이브와 다음 페이지도 제한된 횟수로 확인합니다. 공개 WordPress 날짜 검색은 그 매체가 실제로 API를 안내한 경우에만 사용하며, 발견한 링크의 원문 발행일·본문을 다시 검증합니다. 이전 주차 기사로 빈칸을 채우지 않습니다.
- Google의 중간 검색주소가 풀리지 않거나 검색 결과 대신 전환 안내 페이지가 나오면 실제 언론사 원문 접속 실패와 구분합니다. 같은 빈 검색을 반복하지 않고 공개 매체 경로로 보완합니다.
- 국내기사는 해당 축종의 **독립적인 해외 가격·수급·교역 사실**을 문단별로 확인합니다. 라면 수출, 달걀 조리법, 치킨 브랜드·매장 운영 수치를 축종 시장정보로 대신하지 않습니다. 해외 돼지고기 CPI처럼 본문에 실제 품목 물가가 있는 기사는 계속 허용합니다.
- 한국어 원문의 완결된 사실과 명확한 외국어 통계는 검증 후 직접 압축·번역합니다. 나머지만 로컬 AI로 교정하며, 길이·원문 수치·단위·전망·한 줄/두 줄 배치는 별도로 검사합니다. 줄 배치 실패도 이미 확보한 다른 원문으로 복구할 수 있습니다.
- 항목당 최대 2회의 AI 교정 예산은 공급자의 과금·서비스 이용 한도가 아닙니다. 재시도가 끝나면 실제 길이·문체·수치 실패 사유를 표시합니다. 미완료 항목을 꾸며 채우지 않으며, 나머지 완료 문구의 복사·부분 HWPX 다운로드는 유지합니다.
- AI 예산은 실제 추론 시간만 차감합니다. 기사 검색·PDF OCR에 오래 걸렸다는 이유로 뒤쪽 항목의 AI 호출이 시작도 못 한 채 만료되지 않습니다. 동일 USMEF PDF는 다시 내려받은 원본 바이트·추출 버전이 일치할 때만 로컬 원문 캐시를 재사용해 서버 재시작 후에도 OCR 중복을 줄입니다. 캐시는 Git에서 제외된 `output/article_source_cache/`에 저장되며 완료 요약이나 선택 날짜를 사실 근거로 재사용하는 방식이 아닙니다.
- 실제 수집 검증은 `python -X utf8 work/verify_article_pipeline.py 2026-09-04`처럼 날짜를 지정해 실행할 수 있습니다. 결과·경과시간·실제 원문 날짜·내용/줄 배치 검사 영수증은 로컬 `output/article_pipeline_verified_*.json`에 저장됩니다. 검색 결과나 고정된 예시 기사로 대체하는 검증이 아닙니다.

### 완료된 기사 초안을 한글 보고서에 반영

1. **보고서 생성**에서 가격·표·그래프가 현행화된 HWPX 파일을 내려받습니다.
2. **기사 초안**에서 같은 주차의 보고 기준일을 선택해 기사를 찾고 완료된 초안의 원문을 검토합니다.
3. 상단 **기사 초안을 한글 보고서에 반영** 영역에 해당 HWPX를 선택하거나 드래그합니다.
4. **기사 반영 한글파일 다운로드**를 누르면 8개 현지동향과 4개 국내기사 제목·출처·요약이 해당 위치에 들어간 새 파일을 받습니다. 원본 파일은 바뀌지 않습니다.

현재 화면의 완료 초안을 사용하므로 기사 재검색이나 AI 재요약을 하지 않습니다. **완료된 초안이 1개 이상이면 부분 반영도 다운로드할 수 있습니다.** 미완료 항목의 기존 제목·요약은 지워 빈칸으로 두며(양식 기호는 유지), 화면에 반영 건수와 빈칸 건수를 표시합니다. 모두 미완료이거나 작업 중이면 반영하지 않습니다. 가격값·표·그래프·문서 기준일은 그대로 보존하며 기사 문단만 교체합니다. 이 단계는 HWPX ZIP/XML을 직접 편집해 한글·Excel 실행이 필요하지 않습니다. 구형 `.hwp`는 한글에서 `.hwpx`로 저장한 뒤 올려 주세요. 국가·축종별 기사 위치가 빠진 다른 양식이나 잘못된 완료 초안은 반영하지 않고 안내합니다. 업로드는 요청 전체 20MB 이하이며, 완료된 원문 날짜는 선택 주의 일요일~토요일 범위여야 합니다.

기존 **보고서 문구 복사**도 계속 사용할 수 있습니다. 날짜·파일·초안을 변경하면 이전 반영 결과를 해제하며, 재다운로드 링크와 성공·실패 메시지는 업로드 영역에서 바로 확인할 수 있습니다.

보고서용 한 줄 문장을 자동으로 만들려면 이 PC에 [Ollama](https://ollama.com/download)와 로컬 모델이 필요합니다. 설치 후 PowerShell 또는 명령 프롬프트에서 한 번만 실행하세요.

```powershell
ollama run qwen2.5:3b
```

`qwen2.5:3b`는 이 PC의 기본 로컬 모델입니다. 작은 모델의 번역·수치 오류 가능성이 있어 원문 정형 압축을 우선하고, AI 문구도 원문·문체·줄 수 검사를 통과해야 완료합니다. 메모리가 적으면 `qwen2.5:1.5b`를 받은 뒤 아래처럼 지정할 수 있지만, 더 작은 모델은 요약 정확도가 낮아질 수 있습니다.

```powershell
$env:OLLAMA_MODEL="qwen2.5:1.5b"
python app.py
```

Ollama는 기사 원문을 이 PC의 `127.0.0.1:11434` 로컬 서버에만 전달합니다. 기사 후보·초안 결과는 선택한 보고 기준일별로 현재 브라우저에 저장되며, **보고서 문구 복사** 또는 **기사 반영 한글파일 다운로드**로 한글 보고서에 옮길 수 있습니다. 기사가 아직 없거나 발행사 페이지가 일시적으로 열리지 않으면 다음 실행 때 다시 확인합니다.

독일 가격의 `유로/kg`은 `독일 ÷ 100`으로 계산해 소수 둘째 자리까지 반올림합니다. 환율을 수집하는 모든 시트의 USD·EUR·JPY·BRL·AUD 매매기준율은 네이버 증권에서 가져옵니다. 기준일 값이 있으면 그대로 사용하고, 주말·휴장일 등으로 값이 없으면 기준일 이전의 가장 최근 게시 값을 사용합니다. 이전 값도 없으면 해당 행을 보류하며 미래 값이나 0으로 대체하지 않습니다. 기존 환산식과 JPY의 100엔 기준은 유지합니다. 생성한 파일은 브라우저 다운로드 폴더와 프로젝트의 `output` 폴더에 저장됩니다.

### 한글 보고서 표 현행화

Excel 생성이 끝나면 같은 보고 주차(가장 최근 목요일 기준)의 값이 한글 보고서 양식의 8개 표에도 자동으로 입력됩니다.

- 소고기: 미국·호주
- 돼지고기: 미국·EU(독일)
- 육계: 미국·브라질
- 계란: 미국·일본

표 안의 `2025년`, `2026년 전주`, `2026년 이번 주`, 전주·전년 대비, 원화 환산 값만 바뀝니다. 제목, 본문 문장, 뉴스 문구, 그림과 그래프는 이번 단계에서 그대로 둡니다. 다운로드 영역에서 **Excel 현행화본**과 **한글 표 현행화본**을 각각 받을 수 있습니다.

이 기능은 로컬 Windows에서만 동작하며 아래가 필요합니다.

- 한글(Hancom Office) 2020 이상 설치
- 프로젝트의 `report_template/weekly_overseas_market_report_table_template.hwp` 양식 파일 유지

한글 프로그램이 설치되지 않은 PC 또는 Render 같은 Linux 서버에서는 Excel 생성은 가능하지만 한글 표 현행화본은 만들 수 없습니다.

계란-일본 시트는 `일본(엔/kg)`이 비어 있는 지난 주차만 찾습니다. 해당 날짜의 도쿄 M란 기준치를 입력하고, 네이버 증권의 JPY/KRW 매매기준율(100엔 기준)을 `환율(1엔=x원)` 열의 기존 양식 방식에 맞춰 입력합니다. 원화 가격은 기존 `일본(엔/kg) × 환율 ÷ 100` 계산식으로 갱신됩니다.

계란-미국 시트는 주차 행의 금요일 기준으로, 같은 주 월요일의 USDA Slug ID `1427`에서 첫 표 `Total / Total / 6-Area Total` 재고량을 가져옵니다. 같은 금요일에 발행된 Slug ID `2848`에서는 첫 표 `National Shell Eggs - Caged`의 `Large / Average Price`를 가져옵니다. USD/KRW 매매기준율을 함께 입력하며, 양식에 있던 단위·원화 환산 계산식은 그대로 유지됩니다.

닭-미국 시트는 주차 행의 날짜와 같은 날 발행된 USDA 보고서를 사용합니다. Slug ID `3208` 첫 표 `Current Day Slaughter`의 `Chicken (Young) / WTD`는 `주간도축량` 열에, Slug ID `3646` 첫 페이지 `WOG Trading by Size`의 `National Composite WOGS / Wtd Avg`는 `미국(cents/lb)` 열에 입력합니다. 천두·단위·원화 환산 등 양식에 있던 계산식은 변경하지 않습니다.

소-호주 시트는 목요일 기준일을 사용합니다. 다음 날 금요일의 MLA National Slaughter Cattle 표 `합계 / Count`를 `도축두수(두) / 호주` 열에 입력하고, 해당 목요일의 MLA EYCI를 `EYCI / 호주(센트)` 열에 입력합니다. AUD/KRW 매매기준율과 양식의 기존 천두·AUD·원화 환산 수식도 함께 갱신합니다.

닭-브라질 시트는 주차 행의 금요일과 같은 날짜를 CEPEA 동결 닭고기 가격 시리즈에서 찾아 `À vista R$`(R$/kg)만 입력합니다. BRL/KRW 매매기준율도 함께 입력하며, 양식의 기존 `브라질(R/kg) × 환율` 계산식으로 원화 가격을 갱신합니다.

소-미국의 `usda 수정`은 수정 후 값입니다. 다음 주 뉴스의 전 주 도축두수가 이전 주의 도축두수와 다를 때만, 이전 주 행의 `usda 수정` 칸에 그 값을 기록합니다.

### 축산 기사 초안의 문체와 선정 기준

- 사용자 제공 2026-08-13~2026-09-17 보고서 6개의 국가·축종별 문체 예시 **72개(12항목 × 6주)**를 기본 참고 자료로 유지하며, 공개 게시판에서 확인한 선별 예시와 출처 근거는 `report_template/article_editorial_examples.json`에 저장합니다. 파일명 20260904 문서의 내부 보고일은 9/10입니다. 기사 주제와 사실 구조에 맞는 소수의 예시만 골라 번역·압축 시 참고합니다. 모델 가중치 재훈련이 아닌 참고 예시 적용이며, 과거 사건·수치를 새 주차 사실로 재사용하지 않습니다.
- 기존 소고기 문체와 축종별 보고체 예시를 적용해 핵심 이슈와 **원문에 명시된 원인·시장 영향**을 요약합니다. 같은 주간 생산·도축 수치를 반복하는 후보보다 소비자가격·대체소비·교역정책·수출입·운송비·인력·산업구조의 중요한 변화를 우선합니다. 영어·포르투갈어·일본어 원문은 한국어로 작성하며, 요약 본문은 공백 포함 **현지동향 40~95자, 국내기사 40~80자**입니다(제목·매체·날짜·현지동향 접두어는 별도). 국내기사도 ‘이어간다·시사한다·전망된다’ 대신 ‘지속·시사·전망’ 등 명사형 보고체로 끝냅니다.
- **미국 소·미국 닭 현지동향만 65~85자 중심의 최대 두 줄**, 호주 소·브라질 닭을 포함한 나머지 **10개 요약은 40~50자 중심의 한 줄**로 정리합니다. 글자 수는 작성 목표이며 근거가 짧으면 억지로 늘리지 않습니다. 모든 요약은 최소 40자를 지키고, 중요한 수치·단위·전주/전년 비교·부정·승인 대기·가능성은 유지합니다. 자연스러운 띄어쓰기를 우선하며 띄어쓰기를 지워 길이를 줄이지 않습니다. `363만 2000마리`, `1억 8968만 9000마리`처럼 숫자 묶음도 띄어 쓰며, 수량·단위 검사는 같은 합계를 유지합니다. 이미 완료된 초안에도 같은 사실을 보존하는 정형 표현 압축을 적용하며, 문장을 글자 수로 잘라내거나 의미 없는 문구로 늘리지 않습니다. 현재 저장 키는 `weekly-overseas-report-livestock-brief-v26-sunday-week-v1`입니다. 이전 초안은 삭제하지 않지만 새 기준의 초안으로 재사용하지 않습니다.

JA 일일 시세는 적합한 설명형 대안이 없을 때 유지합니다. 원문 연도가 검색 날짜와 다르면 검색 날짜로 덮어쓰지 않습니다.
- 국내기사 네 칸은 원본 URL·네이버 원문 별칭·정규화 제목·동일 본문 재전송을 비교해 **같은 기사를 중복 사용하지 않습니다**. 다른 칸에서 선정한 원문을 제외한 기존 검증 후보부터 다시 고르고, 부족한 경우 한정된 보완 검색을 재사용합니다. 같은 원문을 축종명만 바꿔 완료 처리하지 않으며, 해당 주차에 중복이 아닌 적합한 원문을 확보하지 못하면 그 사유를 표시합니다.
- **12개 항목마다 최소 한 건의 검증된 요약을 확보하는 것을 목표로 관련성 기준을 단계적으로 넓힙니다.** 같은 원문 풀에서 `직접 시장 보도 → 수급·물가 설명 → 유사 시장 정보` 순으로 확인하며, 단순히 요약하기 쉽다는 이유로 강한 관련성의 기사를 약한 기사로 바꾸지 않습니다. **소비자물가·CPI·유가 등의 제목을 일괄 제외하지 않습니다.** 제목에 축종이 없어도 본문이 해당 축종의 공급·수요·가격 원인을 설명하면 사용하며, 그런 설명을 확보하지 못할 때만 독립된 가격 지표·교역·소비 등 연관 정보를 보완으로 사용합니다. 돼지고기가 단순 비교 대상인 닭고기 기사나 계란 논란 속 과거 접근 약속만으로 돼지 기사를 만들지는 않습니다.

- USMEF가 아직 발행되지 않은 주는 날짜가 본문에 명시된 TCFA 시장 보고서와 Swineweb의 미국 돼지 시장 원문으로 보완합니다. 브라질은 AviSite·ABPA 연결 실패 시 Portal do Agronegócio·O Presente Rural의 공개 목록에서 원문 링크를 직접 찾습니다. 검색 연결 실패를 기사 부재로 간주하지 않으며, 다른 나라 기사에 미국 가격이 언급됐다는 이유만으로 미국 기사로 선정하지 않습니다.
- 한국어 기사는 본문 뒤쪽의 해외 시장 대목까지 확인합니다. 요약에는 검증한 전체 원문을 전달하고, 화면용 짧은 발췌문만으로 작성하지 않습니다. USDA·JA의 날짜가 확인된 정형 시장 자료, 명시적인 수입·수출 및 수급·가격 문장은 실제 숫자와 조건을 읽는 정형 압축으로 먼저 처리합니다. 과거 요약이나 특정 주의 수치를 저장해 재사용하는 방식이 아니며, 부정·정정·지역·기간·단위가 다른 자료는 해당 규칙을 적용하지 않습니다.
- 쇠고기 품질등급은 `초이스 등급`, `셀렉트 등급`처럼 등급임을 명시합니다. TCFA가 인용한 USDA 쇠고기 컷아웃은 `쇠고기 도매가격 지표(100 파운드당)`로 설명하며, 중량 단위는 USDA의 해당 지표 정의에 근거합니다. 비교 기간은 원문에 명시되지 않은 전일비·전주비로 추정하지 않습니다.
- 생성 문구가 검사를 통과하지 못하면 이미 확보한 다른 원문의 검증 가능한 정형 요약도 끝까지 확인합니다. 항목별 모델 호출 2회·45초와 전체 180초의 기존 예산은 늘리지 않으며, 예산 소진 후에는 모델 재호출 대신 검증된 원문 압축으로 복구합니다. 이 경로도 최소 글자 수·명사형·수치와 문서 줄수 검사를 동일하게 통과해야 완료로 표시합니다.
- 관련성을 넓혀도 **해당 주 일~토, 실제 공개 원문·발행일·언어·대상 국가·축종, 국내 네 기사 중복 방지, 원문 수치·단위·비교기간·부정 표현, 최소 40자·보고체·줄 수 검사는 유지**합니다. 다른 축종의 수치나 `돼지고기를 포함한 축산물`의 종합 상승률을 돼지고기 개별 수치로 바꾸지 않습니다. 실제 원문이 없거나 접근·사실 검증이 불가능하면 허위 문구로 완료하지 않고 남은 사유를 표시합니다. 미완료 칸은 기존 부분 한글 반영 기능에서 빈칸으로 내려받을 수 있습니다.

### 공개 주간 해외 축산물 시장 동향의 참고 자료

- [축산물품질평가원 공개 게시판](https://www.ekapepia.com/v3/board/list.do?menuSn=28&boardInfoNo=0153)의 내려받아 확인한 보고서는 문체·주제·출처의 참고 자료로 사용합니다. 전체 원문과 추출 기록은 별도 오프라인 검토 자료로 보관하고, 실행 중에는 선별된 예시와 매체명·보고서 날짜·쪽 등 출처 근거만 로컬에서 읽습니다. **기사 초안 실행 때마다 과거 게시판 전체를 다시 수집하지 않습니다.**

- 인용된 국내 매체는 검색 풀을 넓히는 단서이지 허용 매체 목록이 아닙니다. 과거 매체명을 현재 기사 출처로 단정하거나 보고서 표 하단의 가격 데이터 출처를 현지동향 문장의 원보도로 간주하지 않습니다. 실제 원문 URL·발행일·국가·축종·시장 관련성을 다시 확인합니다.
- 보고서 머리말 날짜·게시판 등록일·기사 발행일은 구분합니다. 과거 보고서에 이전 주 기사나 오류가 실렸더라도 현재의 **선택일이 속한 일요일~토요일 기사만 사용**하는 기준은 유지합니다. 의학적 ‘계란 변이’처럼 식용계란 수급·가격과 무관한 키워드 기사, 비교 기준이 충돌하는 수치는 선정·사실 검증의 모범으로 사용하지 않습니다.

### 기사 반영 HWPX의 서식

- 사용자가 올린 가격 현행화 HWPX 자체를 양식으로 사용합니다. 원본 파일은 덮어쓰지 않고, 새 파일의 현지동향 8개·국내기사 4개 위치만 교체합니다.
- 현지동향 본문과 접두어의 **`(현지동향)` 전체는 휴먼명조 13pt**, 현지동향의 그 외 완결된 괄호는 11pt입니다. **국내기사 제목·매체명·날짜·요약은 괄호 안까지 전부 한양중고딕 12pt**로 통일하고, 한글·영문·숫자 등 언어별 글꼴도 중고딕으로 맞춥니다. **국내기사 네 제목은 매체·날짜까지 모두 굵게·검정 실선 밑줄**을 적용합니다. 기존 양식의 닭·계란 제목이 일반체이더라도 제목 전용 복제 서식에서 동일하게 보장하고, 요약 본문 서식은 바꾸지 않습니다. 과거 run 길이에 따라 새 문장을 배분하지 않아 숫자 중간의 글자 크기가 달라지지 않습니다.
- 기사 전용 서식의 장평·상대 크기는 언어별 100%, 글자 위치는 0으로 고정합니다. 현지동향은 한글·영문·숫자·한자·기호·사용자 언어까지 휴먼명조, 국내기사는 모두 한양중고딕으로 통일합니다. 업로드 양식에 없는 언어별 글꼴 정의는 기존 해당 글꼴 정의를 복사해 추가하며, 원본 공용 서식·가격·그래프는 변경하지 않습니다.
- 현지동향 접두어는 `- (현지동향)`입니다. **자간 0**에서 실제 칸 너비 100%를 기준으로 확인하고, 넘칠 때만 같은 사실을 유지하는 정형 문구 축약을 먼저 시도합니다. 요약은 필요한 최소한의 자간만 조정하며 **-20보다 낮추지 않습니다**. **12pt 국내기사 제목만 별도로 최저 -30까지 허용**하여 한 줄에 들어가는 가장 덜 압축된 값을 선택합니다. 짧은 본문·제목은 자간 0을 유지하며, 그래도 맞지 않는 제목은 생략·글꼴 축소 없이 자연스럽게 줄바꿈합니다. 요약의 두 줄 허용은 미국 소·미국 닭에만 적용합니다. 나머지 10개 요약이 -20으로도 맞지 않으면 수치·단위·방향·조건을 보존한 한 번의 AI 교정을 시도하고, 그래도 넘치면 완료 처리하지 않고 구체적인 줄 수 오류를 표시합니다. 이 미완료 항목은 한글 반영에서 빈칸으로 처리할 수 있습니다.
- 초안 완료 전에는 기본 보고서의 글꼴·숫자 폭·괄호 크기로 줄 수를 보조 검사하고, HWPX 반영 시에는 업로드 파일의 실제 칸 너비로 다시 검사합니다. 로컬 캐시를 사용하는 읽기 전용 검사이며, 이미 맞는 문구는 추가 AI 호출·검색 없이 통과합니다. 두 줄 허용 현지동향은 빠른 내어쓰기(Ctrl+Shift+Tab)처럼 `(현지동향)` 시작에 맞춥니다. 원본 첫 줄 위치·줄간격·정렬은 유지하고 해당 기사 문단만 여백 속성을 복제합니다. `python-hwpx==6.8.0`은 줄 경계 측정용이며 원본 문서를 다시 저장하지 않습니다.
- 국내기사 제목 뒤의 ` - 머니투데이`처럼 구분자로 붙은 매체명이 인용 괄호의 매체명과 정확히 일치하면 제목에서만 제거합니다. 실제 제목에 쓰인 매체명·하이픈이나 다른 매체명은 유지하고, 인용 출처 자체는 삭제하지 않습니다. 화면·복사와 한글 적용에서 같은 제목을 사용합니다.
- 국내기사 제목을 보고서에 표시할 때 내부 큰따옴표는 작은따옴표(`'`)로 바꾸고 바깥 인용부호 `“…”`는 유지합니다. 화면·후보 링크·문구 복사·HWPX에 같은 표시를 사용하며, 저장된 원제·원문 발췌·현지기사 제목은 바꾸지 않습니다.
- `식품저널 foodnews`처럼 확인된 한·영 중복 매체명만 `식품저널`로 정리합니다. 굵은 한양중고딕 HFT의 실제 한글 추가 글자 폭(글자당 0.05em)도 계산하여, 일반 글씨의 폭으로 제목이 한 줄이라고 오판하지 않습니다. 다른 글꼴·일반 본문에는 이 보정을 적용하지 않습니다.
- 원본 문단 줄간격은 유지합니다. 지정된 HFT 글꼴의 영문·숫자·공백 폭은 실제 한글 PDF 내보내기에서 계측한 폰트 폭을 사용합니다(한양중고딕 공백 0.5em 등). 알 수 없는 글자/글꼴은 기존 보조 측정으로 돌아갑니다. 임의의 4~7% 안전 여백을 빼지 않으며, 실제 표시를 보조 추정만으로 보장하지 않습니다.
- 소·돼지 다음에 있는 기존 두 번째 페이지 제목의 페이지 나눔을 유지합니다. 가격 표·그림·그래프 크기와 기존 공용 글자 속성은 바꾸지 않습니다. 글자 폭과 예상 줄 수는 보조 추정값으로, 실제 페이지 수는 한글 프로그램에서 확인해야 합니다. 글꼴·한글 버전·긴 제목에 따라 줄바꿈이 달라질 수 있습니다.
- v8부터 정형 원문 압축·번역 결과의 바로 사용·AI 작성·한 번의 교정·이전 국내기사 경로 모두에 최소 40자 검사를 적용합니다. 국내기사의 알려진 긍정 종결만 의미를 유지해 명사형으로 바꾸며, 부정·조건부·알 수 없는 동사는 원문 근거로 재작성합니다. 종결 변환 후 길이를 다시 검사하고, 원문에 없는 수치·원인·전망이나 공백·상투어로 길이를 늘리지 않습니다. 너무 짧은 교정 결과는 완료 처리하지 않습니다. 현재 브라우저 저장 키는 위의 v24 기준을 사용하며, 이전 버전 초안을 새 기준에서 재사용하지 않습니다(기존 저장값은 삭제하지 않음).
- v9은 MLA의 소 시장 구간을 양·어린양 통계와 분리합니다. 단위가 생략되어도 명시적인 소 가축시장 출하두수 문장에 있는 총량·전주 증감을 함께 보존합니다. 브라질 닭고기의 EU 교역 재개는 능동·수동 포르투갈어 표현을 읽고, 가능성과 추가 승인 절차를 유지합니다. 번역 검증 실패에는 잘못된 모델 사실이 아닌 원문으로 한 번 교정하며, 통신 장애나 취소를 번역 실패로 재시도하지 않습니다. 회의 날짜·메뉴·사진 설명보다 기사 본문을 우선하며 한국 국내 물가 기사를 해외 돼지고기 기사로 오인하지 않습니다. 정형 규칙에는 주차별 URL·숫자·완성 요약을 고정하지 않습니다.
- 국내기사는 해외 해당 축종의 실제 수급·가격·교역 사건을 우선합니다. 보고서 예시처럼 북한·홍콩·베트남 등도 포함하며, 한국으로의 수입·수출·국제 운송·검역 사건도 허용합니다. 행사·레시피·자료집·등급제 소개·증시의 잠깐 품목 언급·프랜차이즈 매각은 제외합니다. 한국 마트 할인행사와 국내 계란 가격정보 소송도 해외 시장동향으로 쓰지 않습니다. 제목만이 아닌 본문의 실제 국가·품목·시장 문맥을 확인합니다. NAVER API는 날짜순 100건씩 최대 5페이지를 확인하며, 보고기간 시작일보다 오래된 결과에 도달하면 중단합니다. 탐색 단계별 원문 최대 18개를 확인하며, 첫 10개에서 적합한 원문을 못 찾으면 다음 8개까지 확인합니다(원문 2개 확보 시 조기 종료). 같은 실패 URL은 검색 단계가 달라도 중복 확인하지 않습니다. 한 항목의 실패는 다른 항목을 중단하지 않습니다.
- 지정 매체에서 없으면 다른 짧은 검색어로 NAVER/Google News를 보완하고, 공개 Bing News RSS의 원문 링크와 일반 Google 검색도 확인합니다. 발행일은 최종 원문에서 다시 확인합니다. 선택일이 속한 일요일~토요일 범위만 사용하며, 접근 제한을 우회하거나 검색 요약문만으로 초안을 만들지 않습니다. 이전 금요일~보고일 기준의 저장 초안은 새 검색 기간에서 재사용하지 않습니다.
- 이미지형 USMEF PDF는 문서 전체를 작게 축소하지 않고 겹치는 구간별 OCR로 실제 시장동향 제목 위치를 찾습니다. 주차별 문서 높이가 달라도 소·돼지 본문을 분리하며, 한 번 읽은 PDF는 공유합니다.
- Windows에서 기사 실행 시 이미 설치된 로컬 Ollama가 꺼져 있으면 숨김 실행으로 `ollama serve`를 시작합니다. 원격 서버는 실행하지 않으며, 모델 설치·다운로드·API 키 변경은 하지 않습니다. 한국어 원문 압축과 정형 통계는 AI가 없어도 작성할 수 있습니다.
- 첫 원문 요약 검사가 실패하면 다른 해당 주차 원문을 최대 한 번 더 찾아 요약합니다. 축종이 빠진 문장, 원문에 없는 날씨·상품, 외국어 문자·수치를 검사하지만 모든 의미 오류를 자동 검증할 수는 없으므로 원문 검토가 필요합니다.
